## 问题与合同

同一制作单版本、页码和成品 SHA 的审核可以更新。恢复前的审核顺序为 pass → revise 时，必须继承最后的 revise；反向 revise → pass 时必须继承最后的 pass。“最新”以审核记录的追加顺序为准，不能寻找任意历史 pass，也不能依据可能相同的时间戳排序。其他版本、页码或 SHA 的审核不可混用。审核时间可能相同，完整记录也可能重复；归档保留追加位置，不用 JSON 去重删除后来的有效决定。

恢复只继承已有审核证据，不声称发生了新的人工读图。没有匹配审核时仍待复审。恢复目标页和其他继承页使用相同规则，保留原审核历史及图像；最终批准清空，仍由用户查看当前成品后明确批准。批准和导出也必须遵循相同的最新审核规则。
