# P3 素材确认后继续与历史会话恢复

日期：2026-10-15。用户反馈保留参考后继续无响应，并要求素材确认后直接继续。

## 已确认的根因

真实任务的参考选择已成功保存。2026-10-15 14:23:23 的 chat Job 在约 50 毫秒内失败，DSH 没有新增模型 turn。临时复制任务资料与会话，使用本地模型替身复现得到 SessionPersistenceCorruptionError，模型请求数为 0。

旧的历史检索压缩会在 turn 结束后追加 tool/result replacement；DSH v4 要求这种事件属于活动 turn。此前一次运行写入三条这样的替换记录，导致下一次 resume 无法解析。该问题属于本项目会话处理错误，不能归因于用户选错素材或模型没有响应。

## 交互变化

- 保留想用的素材后，点击“确认素材并继续”。弹窗说明保留数量、其余未选项将排除，以及制作单仍需人工审核。
- 用户确认后按顺序保存选择、确认当前版本、发送制作单整理请求；每步使用上一返回版本，不把旧表单强行套到新 revision。
- 不使用参考时提供“不使用参考并继续”；需求与参考已经确认时可直接“继续整理制作单”，不用再回聊天框输入继续。
- 整理出新制作单后自动展示制作单页签。不会替用户确认制作单或触发生图。
- 双击由忙碌状态和同步请求锁拦住。确认发生版本冲突则停止，不发送后续 chat；刷新状态后仍显示冲突信息。
