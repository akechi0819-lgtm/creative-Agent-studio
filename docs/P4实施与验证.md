# P4 实施与验证

2026-10-16。P4 已获施工与公开仓库授权。本报告记录实施方自验证，独立验收须由主审另行执行；不能把 P3 通过或本轮自验证写成完整首版已独立验收。

## 交付能力

- macOS `Start.command` 和 Windows `Start.cmd` 共用准备器与维护逻辑。优先复用合格 Node，否则下载校验固定官方运行时；安装四套锁定 npm 依赖，构建工作台、Canvas 与 DSH 客户端，准备私有 Python／OCR 环境。源码指纹不变时跳过准备。
- 首次配置基础／生图 API；动态端口、重复启动复用、Canvas／模型插件启停，以及异常退出后的残留服务诊断。停止通过本机身份校验，不按猜测 PID 强杀。
- 中文维护菜单与命令入口：停止、备份、恢复、更新和诊断。更新针对当前已取得的源码先备份再重建，不自动选择或拉取远端分支。
- 备份逐文件 SHA-256 校验，恢复先完整校验并保留恢复前数据。任务 Canvas 状态与原图新增本机持久化，纳入备份；旧浏览器 IndexedDB、个人浏览器资料和全局客户端配置不迁移。
- 区域检测使用跨平台本地 OpenCV、Tesseract 中英文离线模型，替换 Swift／Vision。范围是二维码、文字行和矩形几何定位；一维条码不在本次实现范围。原有浏览器裁切、分割、拼贴与合成继续使用原像素路径。选型与预设精度门槛见 [区域检测](P4区域检测.md)。
- 公开源码采用清理后的干净根提交，本机 P3 回滚历史和标签保留。Windows Actions 在真 runner 执行安装、构建、OCR、单元测试、区域样例与真实浏览器回归。

普通使用和维护方法见 [本地Web交付](本地Web交付.md)，源码回滚见 [Git版本与回滚](Git版本与回滚.md)。
