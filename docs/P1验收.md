## 本阶段完成的能力

Codex 使用 `scripts/studio.mjs` 创建和恢复任务；需求／来源确认绑定 revision，制作单确认绑定 version。支持一页海报及 3—5 页图文，保留精确文案、来源快照、排除决定和旧执行记录。单任务文件锁与 revision CAS 阻止并发推进，修改使旧确认、审核或最终批准失效。

执行前保存确定的文本／配置节点 ID，生成前保存提交意图。恢复时查询原节点、复用已成功文件，只有 Canvas 明确失败且显式指定 retryPage 才重新提交本页。取消传播到新增 HTTP 连接并停止等待，不保证撤销上游已接受的生成。图片通过 Canvas 实际 Blob 回收；选图更新文件，复审与最终批准绑定实际 SHA-256。共享核心没有 DSH 依赖。

`export` 实现不可覆盖的版本目录和 ZIP，包含图片、准确文案、制作单、来源快照、审核、人工确认、执行节点与文件哈希。ZIP 采用产品已有 Canvas 使用的 fflate，根依赖锁定 0.8.3；审核者可以是实际读图的 Agent，三个确认节点只接受人工身份。CLI 是本地可信入口，并非用户身份认证系统，不能代替宿主核对直接人工指令。
