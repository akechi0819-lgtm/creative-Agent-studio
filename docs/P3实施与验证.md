## 实施范围

此前 P3 实施自验覆盖独立本地 Web 工作台、任务 API、DSH 运行时、当时的模型配置、素材库与 DNA 管理，并把共享任务核心和本地 Canvas 操作接入工作流。界面保留用户认可的三栏结构，当前按 2026-10-15 新授权改为冰蓝与鲸鱼娘主题，见 [主题设计与来源](design/鲸鱼主题与素材来源.md)。用户可在工作台创建任务、整理需求和参考、编辑并确认制作单、执行或恢复任务、在 Canvas 同步候选和选图、检查成品、请求 Agent 实际读图、记录人工复审、人工批准并导出 ZIP。工作台支持取消 Job、恢复持久任务、Canvas 回到前台后的显式变更核对，以及素材管理与 DNA 草稿整理；这些历史验证不覆盖本轮模型来源插件和清洗配置切换。

Canvas 产品体验的 P3 范围是任务级打开、候选同步、成品预览、复审与批准状态核对；用户改图后要求显式同步选图并重新复审。**P4 的安装器、macOS 打包、开机启动集成、干净环境安装与完整交付尚未实施，不能把源码运行入口描述成安装包。**

## 2026-10-15 模型选择与人工手测准备

按用户反馈，设置页增加“获取模型 → 选择模型”，使用当前填写的服务地址与密钥，可在未选择模型前读取列表；保留手工填写 ID。对话输入区支持为当前任务选择后续对话、制作单整理和 Agent 读图使用的基础模型，不改全局默认；运行中禁止切换，Job 与回复显示本轮模型。修正了已有配置同 revision 时表单初始为空，以及 Job 已显示终态但任务占用仍未释放的问题；正常终态发布前先释放占用，避免紧接下一步时误报忙。

本轮完整测试 **101/101**，浏览器模型选择 **12 项通过**，覆盖真实 DSH 运行时发给本地替身的 `model`、正在运行时禁用、设置保存和 390px 布局。两组用户授权测试凭据已写入本机私有配置，默认 `grok-4.7` / `gpt-image-2`，不进入仓库、日志、截图明文或导出。真实只读列表检查分别返回 20、21 个模型，均包含对应默认模型；本轮没有追加真实对话或生图请求，用户原任务保留，后续由用户手动体验全链路交互与速度。

证据：[101 项测试](evidence/p3-model-picker/contract-tests.log)、[浏览器 12 项](evidence/p3-model-picker/verification.json)、[真实只读列表与配置检查](evidence/p3-model-picker/live-list-check.json)。自动化自验不代表用户体验验收或新的独立阶段验收。
