# P3 人工试用交互修复

日期：2026-10-15。范围：用户人工试用后提出的 Web 交互问题；实施自验完成，待用户复测及独立验收。P4 未实施、未授权。

## 修复结果

| 问题 | 当前行为 |
| --- | --- |
| 需求追问需要写长文 | Agent 使用结构化追问卡片，支持单选、多选和可选补充；答案通过普通消息提交并记录。 |
| 消息等待处理完才显示 | 点击发送立即出现消息；执行中持续刷新问题与参考。请求 ID 对账避免重复，未知发送状态保留重试。 |
| 素材检索失败 | 长句查询可拆出关键词；模型只收到有界摘要。命中项进入右侧待选区，由用户保留或排除。 |
| 只能单篇导入 | 支持选择父文件夹，按子文件夹分篇、自然排序图片，批量暂存或顺序 AI 提取；失败可重试，成功项跳过。 |
| 确认表单繁琐 | 明确动作按钮即记录确认，不再弹同义确认；存在未选参考将被排除等额外副作用时只说明一次，不要求填写确认人或说明。内部操作标记为“本机用户”，不冒充实际身份。 |
| 长聊天带走右侧内容 | 对话与工作对象分别滚动，输入区固定；导航栏与右侧工作对象可收起。 |
| 附件需要额外填表 | 图片、PDF 可拖入输入区、点加号选择，或粘贴图片；在同一消息说明用途。支持移除预览，刷新后显示持久附件。 |

附件默认作为本任务待选来源，不自动进入素材库或变成已确认事实。“参考版式，不引用品牌”等说明完整进入对话；右侧保留可选编辑能力。附件上传与消息使用同一请求标识，上传重试复用来源，版本冲突不自动覆盖用户新状态。

文件夹批次保留目录与文件顺序，上传回执避免同批重复；清洗队列切换页面后继续，清洗完成仍需人工校正确认入库。当前采用文件夹选择器，不要求上传 ZIP。单篇导入继续保留为独立操作。

## 本轮交互简化与能力边界

任务运行进度留在主对话中显示，停止操作也留在该卡片里；移除了右下角重复浮窗。成品页点击“通过”或“需要修改”会直接保存当前页复审，填写的备注按原文提交，留空时使用系统说明；页面修改改为直接在主对话描述，不再提供页码预填按钮。逐页复审不会自动批准整份成品，最终人工批准、Agent 读图复审和恢复上一版仍各自保留。

用户随后明确要求开放通用 Canvas 能力，而非制作二维码专用工具。本轮已连接裁切、行列分割、像素重采样、节点移动及显示缩放的桥接与对话入口，像素结果以聊天附件回传。后续补充已新增附件导入、原像素拼接及图内多层合成，替换元素前可清除旧区域；模板批次管理器尚未实现。40 个注册工具的完整核对和接入取舍见 [Canvas 工具接入清单](P3Canvas工具接入清单.md)。

## 检索根因与修复边界

只读查看真实试用聊天及 DSH 工具记录后发现：完整长句精确匹配返回空；单独 KET 实际有 7 篇，但旧工具返回包含历史和完整提取文本的约 31 万字符结果，且没有把候选放入任务。另有查询返回约 48～54 万字符。已改为有限关键词检索、最多 5 条紧凑候选和实际待选暂存，避免“口头说搜过、界面没有参考”。

旧会话中超大的历史检索结果通过 DSH 官方 surface replacement 压缩模型可见内容，原事件保留。不会自动重发用户旧请求，也不会擅自确认来源。
