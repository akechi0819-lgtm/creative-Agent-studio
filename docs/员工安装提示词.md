# Company Lite 员工安装提示词

把下面整段复制到你正在使用的智能体宿主。宿主负责从 GitHub 克隆、读取项目规则、运行命令并接入真实 MCP；员工不操作终端。

```text
请从以下 GitHub 分支开始安装 Company Lite：
https://github.com/akechi0819-lgtm/creative-Agent-studio/tree/codex/company-lite

如果当前宿主工作区没有该分支的克隆，请由你使用可用的 Git/工作区能力克隆仓库 `codex/company-lite`。对应仓库地址是 https://github.com/akechi0819-lgtm/creative-Agent-studio.git。员工不运行终端命令。如果当前宿主无法克隆、运行本地命令或配置 stdio MCP，请指出具体缺少的能力和受阻步骤，不要声称安装完成。

进入克隆后的仓库根目录后，先读取根目录 `AGENTS.md`、`README.md`，以及 `docs/代理宿主使用.md`、`docs/工程进度.md` 和 `.agents/skills/creative-studio/SKILL.md`。此后所有本地命令都从仓库根目录执行。遵守这些项目规则；不要臆测宿主配置路径或能力。

当前支持 Windows 和 macOS；Linux 不支持，也未作适配。先确认当前系统受支持，再检查 Git、Node.js 22.19+（22.x）或 24+、npm 是否可用。缺少基础工具时说明缺项，不要先运行 Node 脚本。然后读取根目录 `company-defaults.json` 并运行 `node scripts/setup.mjs status`。公司非秘密默认值已内置，无需向员工或管理员索取服务 URL：
- `materials.baseUrl`: `https://teedy.apinova.cn/`
- `image.baseUrl`: `https://api.osodm.com`
- `image.model`: `gpt-image-2.5-sunburst`

只在首次安装、配置或故障修复时展示以下五步进度。先展示 `setup status` 的实际初始状态，再开始耗时准备；状态必须来自当前实际检查或当前宿主真实工具调用。每完成一项就更新状态，并明确当前唯一下一步。日常创作不重复安装清单。

1. **源码与依赖**：确认源码已克隆且基础工具可用后展示初始进度，再由你从仓库根目录运行 `node scripts/prepare.mjs`，完成后重新运行 `node scripts/setup.mjs status`。缺少工具时说明具体缺项；不要让员工操作终端或更改系统策略。
2. **本地 Canvas/MCP**：通过 `node scripts/studio.mjs mcp-config` 获取当前源码的 stdio 参数，使用当前宿主实际支持的方式配置本地 MCP，然后实际调用 `canvas_status`。打印配置示例或本机 SDK 测试不算宿主已连接；不能猜固定菜单、目录或配置格式。
3. **素材库 Teedy MCP**：由你运行 `node scripts/setup.mjs login-materials` 并打开命令提供的一次性本机表单。员工只在该表单填写本人 Teedy 账号和密码，不能在普通聊天中发送。表单需实际完成登录、素材查询和非空原件下载验证。之后由你用 `node scripts/materials.mjs mcp-config` 配置真正的本机 stdio MCP，按当前宿主实际调用 `search_materials`、`get_material` 和 `download_file`，确认查询与下载均成功并删除测试原件，再运行 `node scripts/setup.mjs report-host connected search_materials download_file`。不要修改远端内容、标签或 ACL；查询结果或链接不等于原件下载。
4. **图片 API**：使用 `setup status` 返回的内置地址、模型和 revision 生成配置参数。不要猜测图片 Key 管理页 URL；请员工通过公司已提供的正式入口复制 Key，并只在当前对话回复“已复制”。收到这句明确确认后，你才可通过 `node scripts/setup.mjs configure-image @<配置文件> --key-from-clipboard` 仅读取一次本机剪贴板并保存到私有配置，然后运行 `node scripts/setup.mjs check-image`。Key 不得进入普通聊天、仓库、普通命令参数或日志。剪贴板方式不可用时不要要求员工把 Key 发到聊天或终端，说明阻塞原因并暂停该步。
5. **完成**：再次读取实际状态，只在当前宿主的 Canvas MCP 已真实调用、Teedy 登录及 MCP 查询/下载检查通过、图片 API 连接检查通过后报告就绪；否则如实报告未完成项和员工需要做的下一步。

以上安装只检查图片 API 连接，不发起生图、不产生生图费用。之后的创作仍由当前宿主对话收集需求、展示制作单并取得用户确认；任何可能收费的生图只在当前用户明确授权范围内执行。状态未知时先查询，不自动重发请求。宿主必须实际读取生成图片后才能进入审核；只有用户明确批准后才导出成品。
```
