# Company Lite 员工安装提示词

把下面整段复制到你正在使用的智能体宿主。宿主负责克隆源码、读取项目规则、运行命令并接入实际 MCP；员工不操作终端、不需要理解命令或编辑技术配置。

```text
请在当前宿主中安装 Company Lite，并从以下固定 GitHub 分支开始：
https://github.com/akechi0819-lgtm/creative-Agent-studio/tree/codex/company-lite

只在 Windows 或 macOS 上安装。若当前工作区尚无克隆，请用宿主实际可用的 Git/工作区能力克隆 `codex/company-lite` 分支。进入仓库根目录后，先读取根目录 `AGENTS.md`、`README.md`、`company-defaults.json`，以及 `docs/代理宿主使用.md`、`docs/工程进度.md` 和 `.agents/skills/creative-studio/SKILL.md`。所有本地命令从该仓库根目录执行；宿主负责全部命令和配置，不要求员工操作终端、理解命令或编辑技术配置。

首次安装时先展示五项当前真实状态，再逐项更新进度；日常创作不重复安装清单。地址和图片模型从 `company-defaults.json` 读取，不向员工索取 URL。按仓库文档和宿主实际能力完成以下五步，不把某一种命令或配置格式当作所有宿主的唯一做法：

1. **源码与依赖**：确认克隆的是 `codex/company-lite` 分支；确认当前为受支持的 Windows 或 macOS，并检查 Git、Node.js 22.19+（22.x）或 24+、npm；从仓库根目录按项目文档完成依赖准备和 Canvas 构建，检查实际状态。缺少基础工具时说明具体缺项及下一步；不要让员工操作终端或更改系统设置。
2. **Canvas MCP**：按当前宿主支持的方式接入本地 Canvas MCP，并由当前宿主实际调用 `canvas_status`。打印配置或 SDK 测试不算宿主连接成功。
3. **Teedy 素材库**：员工只在项目实际提供的一次性本机登录表单输入本人 Teedy 账号密码。完成真实登录、素材查询和非空原件下载验证后，接入素材 MCP，并由当前宿主实际完成查询与原件下载验证；之后删除测试原件。不要改动 Teedy 内容、标签或 ACL；搜索结果或链接不等于原件已下载。
4. **图片 API 与真实测试图**：从默认值文件取得图片 API 地址和模型。根据当前宿主实际具备的凭据能力，选择专用凭据入口、本机表单、经员工明确确认本次复制后的剪贴板，或其他合适的本机安全方式；不要假定项目已有图片 Key 表单，也不要要求员工在普通对话中发送凭据。某种输入方式不可用时改用其他可用方式；只有确实没有可用方式时才说明阻碍。由宿主把 Key 安全写入本机私有配置并完成 API 连接检查。**本次安装授权包含一张真实测试图，不需要再次向员工确认**：通过当前宿主实际接入的 Canvas MCP 提交一次生成，查询生成状态，确认图片已保存到本机 Canvas 历史，用 `canvas_read_image` 实际读图，并重开画布历史确认可恢复。状态未知时先查询，不要盲目重复可能收费的请求；明确失败可在本次一张测试图授权范围内修复后重试。
5. **完成状态**：重新检查并汇总五项真实状态。只有源码与依赖、Canvas MCP、Teedy 登录及 MCP 查询/下载、图片 API 连接，以及一张真实测试图的生成状态、保存、读图和历史重开全部通过时才报告安装完成；否则如实列出未完成项与下一步。

## 安装验收标准

- 源码位于固定分支；当前系统、运行依赖、依赖准备和 Canvas 构建均有实际检查结果，服务默认值来自仓库文件。
- 当前宿主已真实调用 Canvas MCP 的 `canvas_status`，并真实调用 Teedy MCP 完成登录后的查询和原件下载；SDK 测试、配置示例或搜索链接不能代替实际调用与下载。
- 图片 API Key 已写入本机私有配置且连接检查通过；通过宿主实际调用 Canvas MCP 生成并保存一张测试图，查询状态、实际读图、重开历史均通过。`check-image` 只检查 API 连接，本身不生成图片。
- 最终五项状态与上述步骤保持一致。只有全部通过才报告安装完成；否则列明未完成项、已确认的状态和具体下一步。不要把未知状态说成成功，也不要为未知结果盲目重发请求。

安装中的真实测试图已包含在本次授权内。后续创作仍在当前宿主对话中收集需求、展示制作单并取得相应确认；后续收费生图按当次明确授权执行。宿主必须实际读取生成图片后才能进入审核；用户明确批准后再导出正式成品。
```
