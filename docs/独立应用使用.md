# 独立应用使用

P4 统一启动、首次准备、服务维护与备份恢复的当前入口见 [本地 Web 使用与维护](本地Web交付.md)。以下源码运行说明供开发调试；不作为普通用户首次安装入口。

已有成品需要微调时，直接在聊天里说明“改第几页、改什么、保留什么”。成品审核页也有“对话修改本页”入口；如需统一画风，可指定其他页为风格参考。明确修改指令直接执行，不必重新确认整套素材和制作单。修改后只重审受影响页；“恢复本页上一版”不发起生图。上传已有图的修改也可在对话中说明，完整新创作仍保留首轮确认。详见 [对话局部改图](P3对话局部改图.md)。

P4 双平台入口统一准备运行环境；本文保留开发者直接运行 Web 的方法。阶段实施自验和独立验收分别记录，不把 P3 通过当成完整首版交付。

## 安装依赖与启动

2026-10-15 绘图修复更新后，刷新工作台，并从工作台重新打开任务 Canvas，以加载新的同源转发和配置同步代码。之后保存图片服务配置会同步到已打开的画布，生成前再次读取当前配置。失败页点“重试失败页并继续”，确认一次即可重新提交；状态未知的请求先查询，避免重复生成。

制作单每页可选择实际要传给绘图模型的参考图／Logo。改选需保存新版本并确认；已确认的旧版本不会自动补图。没有选图时界面会明确提示纯文字生图。故障与验证记录见 [绘图参考与配置同步](P3绘图参考与配置同步.md)。

需要 Node.js `^22.19.0` 或 `>=24`。在仓库根目录运行：

```sh
node scripts/prepare.mjs
npm run web
```

统一准备命令按各 lockfile 安装固定依赖并构建工作台、Canvas、DSH client 与来源插件，准备 OCR 环境；不会启动 DSH Agent。启动后终端会显示本机地址，默认端口为 `4310`，并尝试打开浏览器。

可用以下方式调整启动行为：

```sh
npm run web -- --no-open
npm run web -- --port 4311
```

工作台服务只监听本机 `127.0.0.1`。使用 `Ctrl+C` 退出，会关闭本次工作台并停止本产品 Canvas 实例。源码运行不连接旧 Canvas 实例。

## 首次配置

P3 基础 API、来源插件和清洗配置统一已按源码及本机集成范围独立复验通过。WorkBuddy 本人真实登录与实际能力仍待验证，OpenCode 上游限制不变；P4 当前证据见 [P4实施与验证](P4实施与验证.md)。

Studio 只有两类模型 API。基础 API 供 DSH 对话、工具调用、读图、DNA 草稿整理以及 Web／CLI 素材清洗；生图 API 由任务 Canvas 用于图片生成。Codex 推理仍由宿主 Codex 会话完成，不切换到 Studio 基础 API。

基础 API 的来源包括 OpenCode、Kilo、WorkBuddy 国内版（buddy）、WorkBuddy 国际版（workbuddy）和自定义 API。OpenCode、Kilo 不要求用户粘贴来源密钥；OpenCode 当前 chat 会返回 HTTP 502，工作台显示不可用并推荐 Kilo，不绕过平台限制；WorkBuddy 必须由用户本人登录对应区域账号。原有自用 API 配置与使用方式保留；设置页把自用 API 入口置顶，并在托管来源旁提供“使用自己的 API”按钮。模型来源插件在本机 `127.0.0.1` 动态端口运行，并使用本机随机 token；平台额度、速率和可用性由各平台决定，Studio 不承诺免费额度。生图 API 使用用户自定义服务。

在设置页填写模型来源和模型 ID 后可获取来源提供的模型列表；自定义服务按地址和用户密钥查询，WorkBuddy 先完成本人账号登录。自定义 API 的基础和生图配置默认留空；免费来源使用平台提供的访问方式，无需手工粘贴来源 API Key。

基础配置也供素材库和两个清洗 CLI 使用；CLI 从 Studio 私有配置读取基础 API，不再读取 `STUDIO_TEXT_*` 环境变量。已保存的用户自有 API 密钥留在本机私有配置中，工作台普通 API 不回传明文。

连接检查可能产生服务请求或消耗平台额度；生图检查只发送只读模型列表请求，不调用生图。普通生图操作按所选服务的规则处理费用，开始前应确认当前模型与任务。不同平台的额度和服务策略可能变化。

第一次使用图片时，进入任务并点击打开 Canvas。Canvas 与当前任务绑定；配置通过受控的一次性启动交接提供给该任务页面运行时，不经工作台普通 API、日志或持久浏览器存储暴露。

## 创建和完成任务

1. 点击“新建创作”，直接描述想做什么，并可选拖入参考图或 PDF；不需要填写任务名称、创作类型或页数，任务标题自动取首条需求。形式与张数在后续对话中整理，支持 1—5 张，包括两张海报。信息不足时通过点选追问补充，也可自由输入。发送的消息立即显示，处理中可查看操作进度。Agent 可提出需求候选或查找已确认入库的素材；可直接拖入图片或 PDF，并在同条聊天说明用途。上传本身不代表 Agent 已读取或用户已采纳。
2. 在参考区保留想使用的素材，点击“确认素材并继续”。弹窗会说明保留数量及其余未选候选将被排除；确认后自动整理制作单，无须再输入“继续”。不使用参考时可直接点击“不使用参考并继续”。若需求与来源已确认，可点击“继续整理制作单”。Agent 不能代替用户确认制作单或开始绘图。
3. 生成可编辑制作单，人工检查文案、页面顺序、来源和绘图指令。修改后用对应版本明确确认，再开始执行。
4. 执行状态显示为 Job。可取消正在运行的工作；中断后先查看任务和 Canvas 状态，再恢复。状态未知的生图不会自动重发；只在页面明确失败并由用户选择时重试。
5. 打开任务 Canvas 进行人工编辑。返回工作台后，界面会先刷新任务，再在线核对当前结果。检测到哈希变化、原节点丢失或候选集合变化时，会撤销受影响页旧复审和最终批准，保留任务内旧图，并提示同步候选、明确选图、重新复审。Canvas 断连时只显示“未核对”，不会删除已有确认，也不会把结果标作已同步。
6. 对每页查看当前成品并完成复审。模型读图记录是审核建议，不等于用户批准。用户检查全部页面后显式批准当前版本，才能导出。成功后下载 ZIP；同一任务的导出记录和 ZIP 可在任务中查看。

确认操作只需点击按钮并在弹窗中再次确认，不必填写确认人和说明。长对话在左侧独立滚动，右侧工作对象单独滚动；导航栏和工作对象均可收起。

所有状态修改均绑定任务版本。若收到版本冲突或“任务正在处理中”，先刷新并核对当前状态，再决定下一步；不要把旧表单内容直接换成新 revision 重发。

## 素材库与 DNA

在“素材库”可按原顺序导入文件、启动 AI 清洗、编辑正文／摘要／标签、确认后入库、搜索与预览，也可管理自由标签。清洗只产生待校正候选，须人工确认后才成为正式素材。删除素材使用软删除；任务引用保留既有快照。

批量导入时选择包含多篇子文件夹的父文件夹，界面按子文件夹分篇并预览文件顺序。点击“批量导入并提取”后顺序进行 AI 清洗，也可仅批量暂存；切换到其他页面不停止队列，单篇失败不阻塞其他篇。重试只处理未成功的篇目，完成后逐篇校正并确认入库。

附件直接拖入对话输入区或用“＋”选择，在同一消息描述用途，例如“参考内容和版式，不使用对方品牌信息”；不必另填上传表单。发送前可移除附件。

DNA 默认关闭。可先整理草稿、人工编辑并保存；只有显式启用后，后续新任务才会应用。对已有任务的 DNA 快照不会被后台自动改写。

## 数据位置与恢复

默认用户数据目录：

- macOS：`~/Library/Application Support/Creative Agent Studio/`
- Windows：`%LOCALAPPDATA%/Creative Agent Studio/`
- Linux：`$XDG_DATA_HOME/creative-agent-studio/`；未设置时为 `~/.local/share/creative-agent-studio/`

可通过 `STUDIO_DATA_DIR` 指定其他数据根目录。任务、会话、素材、配置和导出保存在该数据根目录；P4 新写入的任务 Canvas 记录和原图也进入任务 storage/，旧浏览器中的数据不自动迁移。源码和用户数据分开。配置包含用户密钥，备份整个数据目录时应保护备份访问权限。备份前先用 `Ctrl+C` 关闭工作台，再复制数据目录；恢复前也先关闭服务，并将目录恢复到原位置或设置相同的 `STUDIO_DATA_DIR`。

重新启动同一仓库和数据目录后，可从最近任务继续查看进度、会话、图片和导出记录。异常结束的 Job 会标记为中断并保留核心检查点；恢复时先核对现有状态，不会自动重新提交不明状态的生图请求。

## 当前交付边界

当前文档覆盖 P3 源码运行方式和工作台操作，不提供 `.dmg`／`.pkg`、自动安装、首次配置向导、自动更新或干净设备验收承诺。P3 实施自验报告一页、三页、五页共九张真实成品已逐页读图并完成三个 ZIP 哈希核对；独立验收仍待进行。证据与边界见 [P3 实施与验证](P3实施与验证.md)。


### 在对话中拼图、贴图与替换图片元素

打开当前任务 Canvas，在聊天上传需要的图片，直接描述“将两张图左右拼接”“把这个图放到海报右下角”“把旧二维码换成新上传的那张”等要求，无需填写工具名。Agent 先读取任务附件与画布真实节点，需要定位时读取图片预览，并通过本机文字、条码或矩形区域检测取得像素框；附件导入 Canvas 后，拼接和贴图由像素工具处理，不调用图片模型重画。

贴图默认保持比例；替换旧元素时先清除目标矩形再贴入新图，可以保留新码本身及其留白。位置不明确或图像不清楚时，会只追问该处；不能凭空承诺已扫码。合成结果作为对话附件供预览与下载，输入原图保留，不自动覆盖已批准成品或代替最终人工批准。当前原尺寸拼接与合成上限为长边16384、总像素32×1024×1024，超限明确报错，不自动降低分辨率。

精确区域定位当前支持本机 macOS Vision／Swift 的 PNG、JPEG 检测。目标不清楚、存在多个候选或检测不可用时会明确提示；不会将预览估算当成已验证的精确位置。
