## 设计范围与方向

目标是让普通内容运营人员在一个工作台里沟通、判断、修改和交付。2026-10-15 用户进一步授权冰蓝主题与带画笔鲸鱼娘外观重构；当前采用冰蓝背景、白色工作面板、蓝色主操作、深蓝文字、细分隔线和清晰中文排版；页序缩略条作为图文制作的识别元素。避免统计后台式主屏，保留足够空间给对话和真实内容。

## 两个独立网页

工作台与 Canvas 可分别打开标签页。新工作台使用 Web UI，后续结合现有 DSH 扩展与事件接口选择最小可行实现，不预设必须改用 Vue。现有 DSH 业务节点切片采用 React，不因文字误写重做。

Canvas 沿用本项目 `third_party/canvas` 副本的稳定上游界面，不另出 Canvas 设计图、不重设计、不重写为 Vue。后续裁剪多余对话／召唤 Agent 的入口及相应服务路径；普通绘图、人工编辑、选图、工具连接和结果回收继续使用上游能力。工具桥接代码中含 Agent 命名不等于召唤能力，不能按名称一概删除。旧 Canvas 与 RAG-Yuki 保持只读。

工作台“打开 Canvas”指向当前任务绑定的正确项目。用户在 Canvas 改图后返回工作台，先同步当前结果或明确选择新图，系统核对当前图与任务绑定结果的差异；更新选图时撤销该页旧审核和最终批准。未同步或结果已变化时，工作台必须阻止旧结果批准与导出。重新实际读图审核、人工确认后才可交付。

## 工作台的信息层级

左侧：新建创作、当前任务、最近任务、素材库、DNA、模型与服务。任务列表显示待确认、进行中、失败、暂停、完成等业务状态，不编进度百分比。任务接续以持久任务与制品为准，聊天历史不承诺跨入口自动互通；同一任务只允许一个入口推进。

中间：需求沟通与可展开的操作记录。过程只显示检索、调用、生成、检查及结果，不展示内部推理。附件和用户当前资料可补充需求；修改需求后明确提醒下游确认已失效。

右侧：随任务状态切换工作对象，保留“参考素材／制作单／成品审核”页签，避免同屏堆叠全部阶段。主要操作固定在工作对象底部，文案明确确认对象与版本。

| 工作状态 | 主要内容及操作 | 合同约束 |
| --- | --- | --- |
| 新建／需求澄清 | 聊天描述＋可选参考图，不预选类型／页数；对话整理 1—5 张（含两张海报）后人工确认 | 展示本次需求及有效 DNA，不静默确认 |
| 参考选择 | 预览、保留／排除、外部补充；确认素材并继续，未选项经弹窗确认后排除 | 全部候选完成决策才确认；未保留素材不进入制作单 |
| 制作单 | 页序、准确文案、画面要求、尺寸、参考；保存修改、确认具体版本 | 改动创建新版本；确认绑定当前需求、来源和 DNA 快照 |
| 逐页执行 | 各页准备／生成／成功／失败／取消／状态待核，已有结果缩略图；停止、查状态、继续、失败页重试 | 真实事件驱动；未知收费结果先查，不自动重发；已有成功页不重复生成 |
| 成品审核 | 放大实际图、逐页选图、实际读图意见及修改位置、人工批准 | 新图与文字变化需复审；审核和批准绑定当前结果 |
| 导出 | 当前版本全页通过并人工批准后导出素材包，显示交付记录 | 导出重新核验制品与批准；过时确认不能放行 |
| 冲突／恢复 | “任务已更新，请重新查看”、占用入口、已完成页、明确失败位置 | 重新读取当前状态并由用户检查，不能仅替换 revision 重发旧内容 |

完整实现须覆盖首次配置、空任务、空素材、等待、失败、取消、重试、版本冲突与成功，不能用静态图或假进度代替。

## 管理区域

素材库采用同一总库与自由标签。导入先暂存，用户点击 AI 清洗，展示解析、清洗状态；正文、图片顺序、摘要、标签可人工修正，确认后才供创作检索。详情区区分原件、提取内容、模型候选和人工修改。支持查找、原件预览、标签管理、更新、删除及引用关系提示；清洗中发生标签操作冲突时提示稍后再试，不局部修改。

DNA 默认关闭、内容空白。自然语言可由 Agent 整理成可读分项草稿，整理不等于保存。用户明确点击保存后才写入；“保存草稿”保持关闭，“保存并启用”同时显式保存启用。模板不自动写入，界面区分草稿、已保存版本及启用状态。新任务采用固定快照；当前任务另有明确“应用新版 DNA”操作，提醒将撤销下游确认并要求重新检查。不会自动记忆对话。

模型与服务使用独立配置入口，首次配置默认空白。基础模型用于对话、读图与素材文字清洗，图片模型独立配置；字段包括服务地址、模型名、密码式凭据及连接检查。区分未配置、检查中、失败和已验证的具体能力；不把可连接当作所有能力均通过。凭据不回显、不进入任务、日志、设计证据或导出。
