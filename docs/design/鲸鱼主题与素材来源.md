日期：2026-10-15。用户在旁支明确授权同步主线程施工，范围为当前 P3 Web UI 主题外观重构，P4 未授权。当前视觉要求取代先前暖白／墨绿配色，保留三栏工作台层级及全部业务交互。

## 视觉系统

工作区采用冰蓝底色 #E9F3FC、浅蓝层 #F3F9FE、白色工作面板、蓝色主按钮 #3B62F6、边框 #C6DCF2、深蓝正文 #0E2A5C、次文字 #45678F。角色识别分布在品牌头像、Agent 头像、侧栏陪伴立绘、空任务欢迎图及实际 Job 的等待／工作／完成反馈；真实参考、制作单、生成图片仍占主要空间，不放覆盖内容的悬浮角色或全屏动画。

沿用系统中文字体、现有字号和密度。任务状态保留警告与错误含义；焦点框、选项、进度及管理页使用同一色彩系统。桌面保留左导航、中间对话、右工作对象；窄屏保留抽屉导航与对话／工作对象切换。此次不改变业务状态机、附件协议、确认规则和 Canvas 界面。
