# 公司版接入与分发

2026-10-17 用户授权：公司版 Canvas 改为与个人版相同的本地实现。业务差异只保留公司 Teedy 素材接入；独立 Company 数据目录、4311 和公司启动入口保留。旧远端服务器、Teedy 挂靠、标签和 ACL 不改动。

## 同事首次使用

管理员提供对应平台的公司成品包。员工完整解压后，Apple 芯片 Mac 双击 `Creative Agent Studio Company.app`，Windows 64 位双击 `Start-Company.vbs`。主包携带 Node、生产依赖和已构建 Web／Canvas／DSH，无需手动 npm 安装或编译。首次仍可能联网准备独立 Python、OCR／Office 依赖和模型；健康环境复用，不宣传完全离线。

1. 填写本人 Teedy 账号密码。素材库地址已预置，继续按现有 ACL 访问；包中没有共享账号。
2. 使用与个人版相同的模型配置。Kilo 等托管对话来源不要求个人 API 密钥；自用 API 才填写相应地址和密钥。图片模型独立配置，Image 2 服务密钥不会被当作对话密钥。
3. 在左侧讨论、选择参考并确认方案。工作台自动准备该任务的本地 Canvas，绘图使用本机已保存图片配置，无需打开公司云端画布或再次填写密钥。

Web／DSH 与 Codex 共用任务核心；Codex 经项目 Skill／CLI，不启动 DSH。Canvas 只执行绘图和图片工具，不召唤 Agent。自然确认、版本／图片 SHA、CAS 和人工最终判断继续保留。

## 公司素材与本机数据

公司库只读检索与预览，本机素材另列。标签和硬条件按明确范围输入，不自动放宽。候选不下载原件；人工保留后才下载正文和附件快照，冻结原件顺序及 SHA-256。正文最多 500,000 字符；单附件 80 MiB、单篇最多 100 附件、合计 250 MiB，失败回滚本次保留。

默认数据目录：Mac `~/Library/Application Support/Creative Agent Studio Company`；Windows `%LOCALAPPDATA%/Creative Agent Studio Company`。默认工作台端口 4311；Canvas 由本机任务服务管理，不依赖公司画布网站。

本机备份包括任务、来源快照、Canvas 节点与原图、回收图、审核、导出和个人配置。备份含私有配置，应作为私人资料保存；运行实例、临时票据、token 和锁文件不打入备份。旧远端 Canvas 数据仍在原浏览器 IndexedDB，不自动迁移；重要旧任务应先在原画布导出。新版不保留远端模式或兼容桥接。

## 管理员预配与构建

部署 JSON 仅包含无凭据的 Teedy HTTPS 地址：

```json
{"schemaVersion":1,"teedy":{"baseUrl":"https://teedy.example.invalid"}}
```

构建时从仓库外或忽略目录注入，运行包内固定为程序目录的 `company-services.json`（Mac 在 app 的 `Contents/Resources/studio/`）。该文件不进入公开源码，包中不包含员工密码、模型密钥、旧任务或个人浏览器资料。员工接口不能更改服务地址；个人密码绑定保存时的 Teedy 服务，管理员更换服务后不会将旧密码发送给新地址。

打包器使用 `--profile company`，核对已验收 P5 run `39001846741` 对应平台 ZIP 和 `.sha256`，复用包内原生 Node 与生产依赖，覆盖当前干净工作树的公司源码及本地 Canvas 构建产物：

```sh
node scripts/package-release.mjs --profile company --target darwin-arm64 --version company-p5.1.3 --base-package /outside/P5/Creative-Agent-Studio-p5-pr.1.9-macOS-arm64.zip --company-services-file /outside/company-services.json --output /outside/company-output
```

Windows 目标为 `win32-x64`。两个平台在各自原生 runner 构建，最终 ZIP 解压后核对 manifest 和首启。Actions secret `STUDIO_COMPANY_SERVICES_JSON` 也只含上述 Teedy 配置。无需更新服务器 Canvas，不部署公网服务。当前下载及验证结果以 [README](../README.md)、[公司版自检](公司版自检.md) 为准。
