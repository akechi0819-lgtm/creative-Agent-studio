2026-10-17。本轮在 `codex/company-edition` 的独立工作区整合已复验 P5 源码 `8cd572e`／交付文档 `125fac2`，并基于同源码双平台原生成品 ZIP 做公司微调。P5 通过范围见 [最终独立复验](P5最终独立复验.md)，公司新增范围另行验证，见 [公司版自检](公司版自检.md)。

## 同事首次使用

管理员提供对应平台的公司成品包。员工完整解压后，Apple 芯片 Mac 双击 `Creative Agent Studio Company.app`，Windows 64 位双击 `Start-Company.vbs`。主包带 Node、生产依赖和已构建界面，不需要员工运行 npm 安装或编译。首次仍可能联网独立准备 Python、OCR／Office 依赖及模型；健康环境复用，符合 P5 已授权方式，不能称为完全离线。

首次引导只有个人配置：

1. 填写本人的 Teedy 素材库账号、密码。公司服务地址只读，无需员工填写；账号按 Teedy 现有 ACL 访问，包中没有公共账号。
2. 按 P5 引导配置基础 API 和生图 API；服务可共用，也可各自配置。账号、密码与两类模型钥匙均写在本人本机 Company 数据目录，不随包分发。
3. 保存后在左侧讨论、选择参考并确认当前方案。工作台自动准备任务工具连接，打开新版远端 Canvas；同事不需要到远端画布再次填模型钥匙。

基础模型用于对话、工具、读图与素材清洗。图片请求通过任务本机受限代理使用本机生图配置；远端只收到模型公开字段和临时工具连接，不收到上游 API Key。桥接 token 留在任务内存，不写入远端浏览器持久化；远端原有个人模型配置不因公司任务被覆盖。

Web／DSH 与 Codex 仍共用任务核心；Codex 通过项目 Skill／CLI，不启动 DSH；Canvas 只执行绘图和机械操作，不召唤 Agent。P5 的自然确认、版本／图片 SHA 与人工最终判断继续保留。

## 公司素材与数据

公司库默认只读检索与预览；个人本机素材另列，不冒充公司库结果。标签和硬条件只按明确范围输入，不自动放宽。候选不下载原件；人工保留后才取得正文和附件快照，冻结原件顺序及 SHA-256。正文最多 500,000 字符，超限明确拒绝；单附件 80 MiB、单篇最多 100 附件且合计 250 MiB，失败回滚本次保留。P5 文件工具可读取这些任务冻结原件。

数据默认独立保存：Mac 为 `~/Library/Application Support/Creative Agent Studio Company`，Windows 为 `%LOCALAPPDATA%/Creative Agent Studio Company`，源码 Linux 为 `$XDG_DATA_HOME/creative-agent-studio-company`（未设时 `~/.local/share/creative-agent-studio-company`）。默认端口 4311；隔离测试使用 `STUDIO_DATA_DIR` 临时目录。

本机备份包括任务、来源快照、回收图、审核、导出和个人配置。远端 Canvas 节点和原图保存在该员工浏览器 IndexedDB，不属于本机备份；任务工具桥接的运行实例文件及 token 不打入备份。不复制旧全局客户端配置、个人浏览器资料或员工运行数据。

## 管理员预配

部署 JSON 只含两个无凭据 HTTPS 地址，不含用户名、密码、模型钥匙或 token：

```json
{"schemaVersion":1,"teedy":{"baseUrl":"https://teedy.example.invalid"},"canvas":{"webUrl":"https://canvas.example.invalid"}}
```

构建时从仓库外（或忽略目录）的文件注入，运行包内固定为程序运行目录的 `company-services.json`（Mac 修正版位于 `Creative Agent Studio Company.app/Contents/Resources/studio/`）。该文件不进公开源码；缺少或格式错误时提示管理员重新提供包，不把服务地址配置责任交给员工。源码与隔离测试可通过 `STUDIO_COMPANY_SERVICES_FILE` 指定同格式文件。员工接口只能保存个人 Teedy 凭据，拒绝更改服务地址。个人密码同时绑定保存时的 Teedy 服务；管理员换服务时，不把旧服务的密码发送给新服务。

打包器使用 `--profile company`，必须校核 P5 run `39001846741` 对应平台 ZIP 及 `.sha256`，复用其中 Node 与生产依赖，覆盖当前干净工作树中公司 allowlist 源码和已构建界面。示例（路径按管理员实际位置填写）：

```sh
node scripts/package-release.mjs --profile company --target darwin-arm64 --version company-p5.1.1 --base-package /outside/P5/Creative-Agent-Studio-p5-pr.1.9-macOS-arm64.zip --company-services-file /outside/company-services.json --output /outside/company-output
```

Windows 目标为 `win32-x64`，基包文件对应 `Creative-Agent-Studio-p5-pr.1.9-Windows-x64.zip`。两个平台分别在原生 runner 生成并从最终 ZIP 解压后运行完整首启检查；源码测试不能替代成品检查。独立 Company workflow 使用仅含部署地址的 `STUDIO_COMPANY_SERVICES_JSON` Actions secret，输出限期候选 artifact，不创建正式 GitHub Release。下载 artifact 的访问权限和保留期按 Actions 页面为准。

## 远端 Canvas 一次性更新

管理员需用本分支匹配的 remote profile 前端更新远端 Canvas；只升级上游版本号不能证明已有任务协议、图片导入／读回和公司图片代理支持。运行 `node scripts/build-company-canvas.mjs` 得到 `.studio-runtime/company-canvas/company-canvas-remote.zip`。包内含静态前端、说明、MIT 许可、文件清单与 SHA-256，不带模型钥匙、员工账号或公司素材。

远端必须 HTTPS 并提供 SPA 路由回退。静态前端使用原 `infinite-canvas` IndexedDB 及 store，不调用通用版本机 `/__studio/*` 存储接口。每个任务使用独立 bridge/projectId；每次从工作台打开使用 60 秒单次票据，消费后立即移除地址栏片段；多个在线标签页目标不明时提示关闭多余页面。

本轮不部署服务器。旧项目记录 Teedy HTTPS 由 Canvas 的 Caddy 承载，重建 Canvas 曾导致遗漏 Teedy 站点或外部容器网络；更新只替换 Canvas 前端，保留原 Teedy 挂靠、Caddy／Compose、外部网络、数据卷和员工 ACL。静态包没有多人服务端数据库，不承诺浏览器或设备间共享画布。

## 验证边界

公司源代码、合成 Teedy、受限模型代理、真实浏览器、成品原生启动、真实员工账号和付费生图分别记录。没有真实账号不宣称 ACL 全面验证；匿名素材列表被拒绝也不能代替员工权限实测。本轮不重放历史付费任务，旧服务和用户数据只读。通用版 P5 独立通过与公司版施工自检分别呈现。

词库辅助沿用旧公开工作台 990 条记录／985 个词项，保留 MIT 许可与来源。命中仅是人工判断提示，不自动批准或修改文案，也不代替实际读图与事实核对。
