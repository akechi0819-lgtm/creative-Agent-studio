# 上游裁剪清单

上游基线：`basketikun/infinite-canvas@3a6b64b602ad062b29fac66902ed18a7ef5fd9dc`。以下删除只作用于 `third_party/canvas` 的集成运行副本；不改上游来源档案。

| 删除路径 | 裁剪理由 |
| --- | --- |
| `.agents/`、`skills-lock.json` | 上游 AI 插件市场和开发技能配置不参与本项目纯绘图桥接。 |
| `.github/` | 上游文档、容器和插件发布工作流不适用于本项目。 |
| `plugins/` | 移除画布远程节点插件 SDK、Codex/ZCode 插件及其 MCP 注册配置；P0 仅保留浏览器画布工具桥接。 |
| `canvas-proxy/` | 独立代理包及 `npx ...@latest` 启动方式不属于本项目服务。 |
| `docs/` | 上游站点源代码、内容和部署配置不是集成运行时文档。桥接协议以 `canvas-agent/docs/Canvas服务P0.md` 为准。 |
| `Dockerfile`、`.dockerignore`、`docker-compose*.yml`、`nginx.conf`、`render.yaml`、`vercel.json` | 删除上游容器、反向代理和托管部署入口；本项目由仓库根启动器管理本地实例。 |
| `assets/` | 目录内为旧 README 的赞助商和服务商宣传图，画布前端不引用。 |
| `SECURITY.md` | 原文的产品范围包含已裁剪的远程插件、API 代理和上游部署，不能作为本项目安全范围说明。 |

保留 `web/` 画布前端、`canvas-agent/` 纯绘图桥接服务，以及 `LICENSE`、`VERSION`、`CHANGELOG.md` 和裁剪版 `README.md`。`canvas-agent` 子目录和上游已发布变更记录不在本次顶层裁剪清单的改写范围内。

## P1 保存格式清理

移除 Canvas project、history、store 的聊天会话类型与 `chatSessions`／`activeChatId` 字段，删除聊天记录保存和聊天图片恢复路径。素材插入及纯绘图状态仍保留。没有为旧聊天字段添加迁移／兼容层。

## P3 运行副本对话路径核对

P3 复查并清理已裁掉的 Codex 聊天翻译文案、未使用的对话面板文案，以及本地存储统计中的旧 `agent_chat_messages` 分支。没有添加旧会话迁移或兼容逻辑。Canvas 连接按钮与状态统一称为绘图工具。

保留 `CanvasToolPanel`、`canvas-agent-ops` 和 `canvas-agent` 的 Agent 命名，因为它们只提供本地绘图 bridge：浏览器发布画布状态并执行节点操作，服务端查询状态、生成图像和回收 Blob。该 bridge 不启动或创建聊天会话。独立浏览器夹具验证了不存在 `/agent/codex/threads/new` 启动路由；普通绘图工具与节点操作未裁剪。
