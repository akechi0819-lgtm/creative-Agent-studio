## 取回旧源码

查看基线：

```sh
git show --stat p3-rollback-ready
```

若需运行或比较旧版本，可在旁边建立独立检出，保留当前施工目录：

```sh
git worktree add --detach ../creative-Agent-studio-p3-restore p3-rollback-ready
```

旧检出需按对应版本重新准备依赖。试运行时应设置独立的 `STUDIO_DATA_DIR`，避免旧代码与正在使用的工作台同时操作真实数据。不要直接对当前工作目录执行破坏性的重置或清理。

P4 按可验证的小步提交。每次交付记录提交号、验证结果，以及尚未执行的 Windows 云端或用户试用项目。
